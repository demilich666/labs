Лабораторная работа №6: Коллекции и дженерики в Java Описание

Работа посвящена изучению Collections Framework и обобщений (Generics) в Java. Коллекции предоставляют гибкие структуры для хранения и обработки групп объектов: списки, множества, отображения. Обобщения позволяют создавать типобезопасные контейнеры, исключая ошибки приведения типов на этапе компиляции.

Основные интерфейсы коллекций

Collection является корневым интерфейсом. List описывает упорядоченные последовательности с доступом по индексу, допускает дубликаты (ArrayList, LinkedList). Set гарантирует уникальность элементов, порядок не определён (HashSet) или сортированный (TreeSet). Map хранит пары ключ-значение, обеспечивая быстрый доступ по ключу (HashMap, TreeMap).

Ключевые принципы

Generics повышают типобезопасность, позволяя указать тип хранимых элементов уже при объявлении коллекции. Iterator обеспечивает последовательный обход элементов без привязки к конкретной реализации. Интерфейсы Comparable и Comparator используются для задания порядка сортировки объектов.

Содержание работы

Подсчет частоты слов (TopWords)
Программа считывает текстовый файл и подсчитывает, сколько раз встречается каждое слово. Для хранения пар «слово – количество» используется HashMap<String, Integer>. Слова приводятся к нижнему регистру и очищаются от знаков пунктуации. Результаты сортируются по убыванию частоты с помощью компаратора, после чего выводятся десять самых частотных слов.

Обобщенный стек (StackMain)
Реализован класс Stack<T> на основе массива, использующий обобщение для работы с любым типом данных. Метод push добавляет элемент на вершину, увеличивая внутренний счетчик. Метод pop возвращает верхний элемент и удаляет его, уменьшая счетчик; при попытке извлечь из пустого стека выбрасывается EmptyStackException. Метод peek позволяет посмотреть вершину без удаления. Конструктор принимает емкость и проверяет ее положительность. В main демонстрируется последовательное добавление и извлечение целых чисел.

Учет продаж в магазине (ProductHash)
Моделируется сервис учета продаж, где товар представлен классом Product с полями name и price. Класс Service содержит HashMap<Product, Integer>, сопоставляющую каждому товару количество проданных единиц. Метод add обновляет значение для существующего товара или добавляет новую запись. printSales выводит все пары товар-количество. getTotalRevenue вычисляет общую выручку как сумму произведений цены на количество. getMostPopularProduct возвращает товар с наибольшим количеством продаж. Переопределение equals и hashCode в Product гарантирует корректную работу в качестве ключа карты.
