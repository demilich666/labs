Лабораторная работа №1: Знакомство с Java и базовые алгоритмы Описание

Программы демонстрируют базовый синтаксис Java: циклы, условные операторы, работу со строками, выделение алгоритмической логики в отдельные методы, а также обработку аргументов командной строки.

1. Primes.java – поиск и вывод простых чисел в диапазоне от 2 до 100.  
Метод isPrime(int n): определяет простоту числа.  
  Для 2 и 3 сразу возвращается true.  
  Для остальных проверяются делители от 2 до √n; если остаток от деления равен 0 – число составное.  
  Метод main перебирает числа от 2 до 100 и печатает те, для которых isPrime вернул true.

2. Palindrome.java – проверка строк, переданных через аргументы командной строки, на свойство палиндрома.  
Метод reverseString(String s): формирует перевёрнутую строку посимвольно с помощью цикла и charAt().  
Метод isPalindrome(String s): сравнивает исходную строку с перевёрнутой, используя .equals().  
Метод main проходит по всем аргументам args, для каждого вызывает isPalindrome и выводит строку вместе с результатом (true/false).
