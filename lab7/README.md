Лабораторная работа №7: Многопоточность в Java Описание

Многопоточность позволяет параллельно выполнять несколько участков кода, повышая эффективность использования процессора и ускоряя обработку данных. В работе рассматриваются базовые механизмы создания потоков, синхронизация доступа к общим ресурсам и координация потоков с помощью методов ожидания.

Ключевые инструменты и методы

Класс Thread и интерфейс Runnable обеспечивают создание и запуск новых потоков. Метод join() приостанавливает текущий поток до завершения целевого потока, позволяя корректно агрегировать результаты. Ключевое слово synchronized защищает общий ресурс от одновременного изменения несколькими потоками. Класс CompletableFuture предоставляет современный способ асинхронного запуска задач и ожидания их завершения.

Содержание заданий

Многопоточное вычисление суммы элементов массива

Класс SumThread расширяет Thread и получает ссылку на массив, начальный и конечный индексы. Метод run в цикле суммирует элементы своего диапазона. Главный поток создает два экземпляра SumThread, каждый обрабатывает половину массива. После запуска потоков вызывается join() для ожидания их завершения, затем суммы, полученные через getSum(), складываются и выводятся на консоль.

Поиск наибольшего элемента в матрице

Класс RowMaxThread, унаследованный от Thread, получает строку матрицы и ищет в ней максимум. Результат сохраняется в поле rowMax. Класс MatrixMaxFinder в методе findMax создает массив потоков по количеству строк, запускает их и ожидает с помощью join(). После завершения всех потоков в цикле собираются локальные максимумы и определяется наибольший среди них, который и возвращается.

Симуляция работы склада

Класс Warehouse хранит массив весов товаров и синхронизированный метод getProduct, который поочередно выдает элементы массива или возвращает -1, если товары закончились. Класс LoaderTask реализует Runnable и в методе run циклически забирает товары, пока они есть, контролируя суммарный вес не более 150 кг. При достижении лимита вызывается unload, имитирующий перенос на другой склад с секундной задержкой. В главном методе запускаются три задачи через CompletableFuture.runAsync, а метод allOf().join() ожидает их завершения. Благодаря synchronized каждый товар выдается только одному грузчику, исключая коллизии.
