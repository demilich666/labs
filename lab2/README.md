Лабораторная работа №2: Объектно-ориентированное программирование на Java Описание

Работа направлена на закрепление принципов объектно-ориентированного программирования: наследования, инкапсуляции, полиморфизма и абстракции. Построена иерархия классов на примере велосипедов, где общая логика вынесена в абстрактный класс, а конкретные виды велосипедов реализуют уникальное поведение.

Основные концепции ООП в проекте

Абстракция: базовый класс Bicycle объявлен абстрактным и содержит абстрактный метод riding(), заставляя наследников предоставлять собственную реализацию.
  Инкапсуляция: все поля protected, доступ к ним организован через геттеры и сеттеры. Детали реализации скрыты, внешний код работает через открытые методы.
  Наследование: классы MountainBicycle, KidsBike и BMX расширяют Bicycle, наследуя его поля и методы, что позволяет избежать дублирования кода.
  Полиморфизм: метод riding() переопределён в каждом подклассе; в классе BMX дополнительно переопределён метод makeSound(). Благодаря этому объекты разных типов, хранящиеся под ссылкой Bicycle, ведут себя по-разному.


1. Абстрактный класс Bicycle (верхний уровень иерархии)
   Поля: color, model, wheelsCount, speed, sound, rotating.
   Статическое поле bicycleCount для подсчёта созданных экземпляров.
   Три конструктора: полный, упрощённый и конструктор по умолчанию – каждый увеличивает счётчик bicycleCount.
   Абстрактный метод riding() – каждый наследник обязан определить способ езды.
   Обычный метод makeSound() с реализацией по умолчанию.
   Статический метод getBicycleCount() для вывода общего числа созданных велосипедов.

2. Наследуемые классы
   MountainBicycle: переопределяет riding() – выводит "Горный велосипед поднимается в гору".
   KidsBike: переопределяет riding() – выводит "Детский велосипед медленно едет".
   BMX: переопределяет riding() – выводит "BMX делает трюки", а также переопределяет makeSound(), меняя поведение на "BMX не имеет звонка".
   Все конструкторы подклассов вызывают конструктор базового класса через super.

3. Главный класс Main
   Создаёт по одному объекту каждого типа, передавая в конструкторы цвет, модель, количество колёс, скорость, характеристику поворота и звук.
   Выводит в консоль свойства созданных велосипедов, используя геттеры.
   Вызывает статический метод getBicycleCount() для демонстрации работы статической переменной.
