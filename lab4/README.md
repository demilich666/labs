Лабораторная работа №4: Исключения и работа с ресурсами в Java Описание

Работа направлена на освоение механизма обработки исключений в Java. Рассматриваются стандартные unchecked-исключения, создание собственных проверяемых исключений, использование блоков try-catch-finally, а также безопасная работа с файловыми потоками.

Ключевые концепции

Иерархия исключений: разделение на проверяемые (checked) и непроверяемые (unchecked) исключения. Проверяемые требуют обязательной обработки или объявления в throws, непроверяемые обычно сигнализируют об ошибках программирования.

Блоки try-catch-finally: try содержит потенциально опасный код, catch перехватывает и обрабатывает конкретные типы исключений, finally гарантирует выполнение завершающих действий независимо от того, возникло исключение или нет.

Собственные исключения: возможность создавать классы-наследники Exception для описания специфических ошибочных ситуаций, повышая читаемость и точность обработки ошибок.

Содержание работы

Вычисление среднего арифметического (ArrayAverage)
Программа обрабатывает массив строк, преобразуя их в целые числа для подсчёта суммы. В цикле намеренно допущена ошибка выхода за границу массива (i <= arr.length). Перехватывается ArrayIndexOutOfBoundsException, после чего выводится сообщение о выходе за границы. Если элемент не удаётся распарсить, ловится NumberFormatException. Блок finally вычисляет и выводит среднее арифметическое тех элементов, которые были успешно обработаны до возникновения ошибки.

Проверка электронной почты (EmailValidator)
Создан собственный класс проверяемого исключения CustomEmailFormatException, наследуемый от Exception. Метод validate проверяет переданный адрес: наличие символа @, позицию последней точки (она должна быть после @), и наличие доменного расширения длиной не менее одного символа после точки. При нарушении любого условия выбрасывается CustomEmailFormatException с понятным сообщением. В main демонстрируется вызов validate с обработкой исключения и выводом результата.

Копирование файла (FileCopy)
Реализовано побайтовое копирование содержимого одного файла в другой с использованием FileInputStream и FileOutputStream. Потоки открываются в блоке try. При возникновении IOException (например, файл не найден или нет прав) сообщение об ошибке выводится в консоль. Блок finally закрывает оба потока, причём каждое закрытие также обёрнуто в try-catch для предотвращения потери исключений.
