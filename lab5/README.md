Лабораторная работа №5: Регулярные выражения в Java Описание

Работа посвящена изучению и практическому применению регулярных выражений (Regex) в Java. Регулярные выражения позволяют описывать шаблоны для поиска, проверки и преобразования текста. В рамках работы реализованы несколько программ, каждая из которых решает определённую задачу обработки строк с помощью классов Pattern и Matcher.

Основные инструменты

Работа с регулярными выражениями в Java строится на классах пакета java.util.regex. Класс Pattern представляет скомпилированное регулярное выражение. Класс Matcher выполняет операции сопоставления с конкретной строкой, используя шаблон из Pattern. Методы find, matches, replaceAll и group позволяют гибко извлекать и заменять подстроки.

Используемый синтаксис

В проекте применяются следующие элементы регулярных выражений:

\d — любая цифра.
\w — буква, цифра или знак подчёркивания.
\b — граница слова.
{n,m} — повторение от n до m раз.
[A-Z] — диапазон символов.
^ и $ — начало и конец строки.
(?=.*[A-Z]) — позитивная проверка (lookahead) на наличие хотя бы одной заглавной буквы.
\\. — экранированная точка.

Содержание заданий

Поиск чисел в тексте (NumberFinder)

Класс NumberFinder извлекает из строки все числа, включая целые и дробные (с десятичной точкой). Используется шаблон "-?\\d+(\\.\\d+)?". Метод extractNumbers получает текст, проверяет на null и пустоту, затем через Matcher находит все совпадения и возвращает список строк. В методе main демонстрируется вывод найденных чисел.

Валидация пароля (PasswordChecker)

Класс PasswordChecker проверяет, удовлетворяет ли пароль требованиям: длина от 8 до 16 символов, только латинские буквы и цифры, обязательно наличие минимум одной заглавной буквы и одной цифры. Регулярное выражение "^(?=.*[A-Z])(?=.*\\d)[A-Za-z0-9]{8,16}$" использует lookahead для проверки условий. Метод check выбрасывает IllegalArgumentException для некорректного входа или выводит сообщение о валидности/невалидности.

Выделение переходов регистра (LetterFinder)

Класс LetterFinder находит в тексте места, где строчная буква непосредственно предшествует заглавной (например, "bC"). Метод highlightMatches оборачивает каждое такое сочетание в восклицательные знаки с помощью replaceAll("([a-z][A-Z])", "!$1!"). Результат выводится в консоль. Предварительно проверяется, что текст не null и не пустой.

Проверка IP-адреса (IpChecker)

Класс IpChecker выполняет валидацию IPv4-адреса. Регулярное выражение состоит из четырёх групп чисел 0–255, разделённых точками: каждая группа описывается как (25[0-5]|2[0-4][0-9]|1[0-9][0-9]|[1-9]?[0-9]). Метод checkIp проверяет, соответствует ли строка шаблону, и выводит соответствующее сообщение. При null или пустой строке выбрасывается исключение.

Поиск слов по первой букве (WordFinder)

Класс WordFinder находит все слова, начинающиеся с заданной буквы (регистр не учитывается). Сначала проверяется, что текст не пуст, а символ является буквой. Затем формируется шаблон "\\b[" + Character.toLowerCase(symbol) + Character.toUpperCase(symbol) + "]\\w*". Matcher обходит текст и добавляет найденные слова в список, который возвращается и выводится на экран.
