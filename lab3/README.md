Лабораторная работа №3: Хэш-таблицы и обобщения в Java Описание

Работа посвящена изучению структуры данных "хэш-таблица", метода цепочек для разрешения коллизий и применению обобщений (generics) для создания универсальных контейнеров. В первой части реализован собственный обобщённый класс хэш-таблицы, во второй — его использование для хранения и обработки информации о товарах по штрихкодам.

  Хэш-таблица: структура, хранящая пары "ключ-значение". Ключ преобразуется хэш-функцией в индекс массива, что в среднем даёт быстрый доступ.

  Метод цепочек: способ разрешения коллизий. Каждая ячейка массива содержит связный список (LinkedList). Если два разных ключа дают одинаковый индекс, они помещаются в один список.

  Дженерики (<K, V>): позволяют создать один класс хэш-таблицы, способный работать с любыми типами ключей и значений. Это исключает необходимость приведения типов и повышает типобезопасность.

Реализация заданий

1. Универсальная хэш-таблица (HashTableExample)
Класс HashTableExample<K, V> реализует базовые операции: добавление, поиск, удаление, получение размера и проверку на пустоту. Внутренний класс Entry хранит пару ключ-значение. Хэш-функция вычисляет индекс как остаток от деления хэш-кода ключа на размер таблицы. При возникновении коллизий элементы объединяются в LinkedList. Метод put добавляет новую пару или обновляет значение, если ключ уже существует. Метод get возвращает значение по ключу, либо null, если ключ не найден. Метод remove удаляет элемент и возвращает его значение, корректируя счётчик размера. Методы size и isEmpty позволяют контролировать состояние таблицы.

2. Система учёта товаров по штрихкодам (ProductHash)
Демонстрируется применение хэш-таблицы для хранения объектов класса Product (название, цена, количество) с ключом типа String (штрихкод). Класс ProductHash содержит собственную реализацию HashTable, адаптированную под конкретные типы. Метод put выполняет вставку или обновление товара. Метод get ищет товар по штрихкоду. Метод remove удаляет запись. В главном методе создаются несколько товаров, производится обновление одного из них, поиск существующих и отсутствующего ключей, удаление и повторный поиск. Результаты операций выводятся в консоль.
